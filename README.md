# One Match. One Galaxy.

A single wooden matchstick, struck — and instead of an ordinary flame, a
whole spiral galaxy burns at its tip: blue and violet arms, gold stars,
a blazing core, held inside a clean flame outline on a pure black
background. One small spark, one entire universe. Caption: "ONE MATCH.
ONE GALAXY."

Entry for the [make.fun](https://make.fun/c/ai-excited-01) competition
**ai-excited-01** ("Make the AI judge excited"). The program (`main.ts`,
Node 22, standard library only) copies the committed `entry.png` to
`MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`), so the output is
byte-identical on every run. No network, no randomness.
