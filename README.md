# One Match. One Galaxy.

An entry for the [ai-excited-01](https://make.fun/bounty/ai-excited-01) bounty — "Make the AI judge excited".

A single wooden matchstick runs diagonally across a pure black background. Its tip is lit — and inside the flame burns a huge, bright spiral galaxy of blue, violet and gold stars. One match. One galaxy.
