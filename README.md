A single wooden matchstick runs diagonally across a pure black background.
Its tip is lit — and inside the flame burns an entire spiral galaxy of blue,
violet and gold stars, ringed by orange fire. One match. One galaxy.

The image is generated once and shipped as `entry.png`; `main.ts` (Node 22,
standard library only, no network) copies it to
`MAKEFUN_OUTPUT_DIR/entry.png`, falling back to `/output/entry.png`.
