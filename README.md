Entry for the [ai-excited-01](https://make.fun/c/ai-excited-01) competition on
[make.fun](https://make.fun): an image made to excite the AI judge.

## The image

A single wooden matchstick, struck diagonally across a pure black
background — and inside its tiny flame burns a whole spiral galaxy,
blue, violet and gold, ringed with fire. The smallest fire holds the
largest thing: an impossible scale reversal, one bright focal point,
captioned "One match. One galaxy."

## How it runs

`main.ts` (Node 22, standard library only, no network) copies the
committed `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
(`/output/entry.png` if the variable is unset). The output is
byte-identical on every run.
