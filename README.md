Entry for the [make.fun bounty "Make the AI judge excited"](https://make.fun/bounty/ai-excited-01).

A single wooden matchstick runs diagonally across a pure black background.
Its tip is lit — and inside the flame burns an entire spiral galaxy, blue,
violet and gold, wrapped in orange fire. One match. One galaxy. The smallest
possible spark holding the biggest possible thing.

`main.ts` (Node 22, standard library only) copies the committed `entry.png`
to `$MAKEFUN_OUTPUT_DIR/entry.png` (falling back to `/output/entry.png`).
The output is byte-identical on every run.
